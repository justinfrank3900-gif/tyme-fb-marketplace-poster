# TYME Auto - Facebook Marketplace Poster

Chrome extension that auto-fills Facebook Marketplace vehicle listings using
the TYME Vehicle Presentation Builder's fetch-listing API as its data backend.

## Install (unpacked)

1. Go to `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked**
4. Select this folder
5. Use as normal from the extension icon while on Facebook Marketplace's create-listing page.
